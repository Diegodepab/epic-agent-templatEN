# Classic Engineering Books — Nano Checklists

Ultra-dense (~35-line) architectural decision digests adapted from `ciembor/agent-rules-books`.
Load **only** the specific file relevant to the current engineering problem on demand — never load all 14 at once.

| Book Checklist | Primary Focus | File |
| :--- | :--- | :--- |

| Clean Code (Martin) | Meaningful names, small functions, formatting, boundaries | `clean-code.nano.md` |
